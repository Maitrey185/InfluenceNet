## ✅ **What is InfluenceNet?**

**InfluenceNet** is a platform designed for:

* **Influencers** — to grow, track performance, schedule posts, and collaborate with brands
* **Brands** — to find influencers, run influencer campaigns, and track campaign ROI
* **Admins** — to monitor platform activity and manage users

It works like a **“performance & campaign hub” for influencers** combined with a **brand marketing engine**.

---

## 🌟 **Core Features at a Glance**

| Feature                  | Description                                                        |
| ------------------------ | ------------------------------------------------------------------ |

| AI-Lite Enrichment       | Sentiment, hashtags, media insights, language tagging              |

## 🎯 **Real-World Usage Scenarios**

### **Influencer Journey**

| Action                  | What happens                                   |
| ----------------------- | ---------------------------------------------- |
| Connect Instagram       | Data sync starts, followers & post data stored |
| Track analytics         | See insights, improvement areas                |
| Plan content            | Create scheduled posts, reminders              |
| Improve strategy        | Use heatmap + high-performing post data        |
| Collaborate with brands | Accept campaign invites & get paid             |

**Example:**
Riya (Fashion Blogger, 50K followers) logs in → sees best posting time (Sat 6pm) → schedules new post → gets brand campaign invite → completes it → payment released.

---

### **Brand Journey**

| Action             | What happens                           |
| ------------------ | -------------------------------------- |
| Create profile     | Add company details & invite team      |
| Create campaign    | Set budget, niche, deliverables        |
| Search influencers | Filter by niche, followers, engagement |
| Invite influencers | Negotiate terms, approve content       |
| Track performance  | Monitor reach, engagement, conversions |

**Example:**
Nykaa marketing team → creates skincare campaign → invites 10 influencers in 50–200K range → views analytics → approves & releases payment.
